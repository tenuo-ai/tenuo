# Repository boundaries

This is the public `tenuo-ai/tenuo` SDK and protocol repository.

## Website work

The current tenuo.ai website lives in the private `tenuo-ai/website`
repository.
For website content, layouts, marketing pages, previews, or publication, inspect
and edit that repository. Read its `CLAUDE.md` and `README.md` first.
Never render this repository's `docs/` as the website or recreate a Jekyll site here.
Use the private site's real Jekyll layout for previews.

This repository retains SDK guides, protocol specifications, examples, and
verification models under `docs/`. These are source documentation, not a second
website. Website deployment is owned by the private website repository; this
repository's documentation workflow only checks and builds API documentation.

Do not copy unpublished website drafts into this public repository.
