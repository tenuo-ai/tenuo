# Prompt injection

Instructions hidden in data that an agent reads and follows. Nobody told any agent in this lab to misbehave; the instruction sits in the `notes` field of another traveler's reservation, on a departure board an honest check-in agent reads while doing its job. This lab assumes the model will sometimes be fooled and asks what still holds when it is: the check runs at the tool boundary, on the real arguments, after the model has chosen what to call.
