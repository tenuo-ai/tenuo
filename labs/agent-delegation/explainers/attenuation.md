# Attenuation

Access that can narrow when it is passed on and can never widen. In stage 6 the check happens when the child is created, in the delegating agent's own process, before any token exists, and again when it is verified. Neither check calls a server. The agent that knows the fact is the agent that narrows: Flight Agent narrows 'any Cancún flight' to UA214 because it is the one that booked it.
