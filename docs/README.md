# SDK and protocol documentation

This directory contains source documentation, integration examples, protocol
specifications, and verification models for the public Tenuo SDK.

The published website and its layouts are maintained in the private
`tenuo-ai/website` repository. Website content changes and previews belong
there, not here.
See [the repository instructions](../AGENTS.md) before working on the website.

Published documentation: [tenuo.ai](https://tenuo.ai/).
